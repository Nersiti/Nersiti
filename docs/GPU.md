# Нейросети на своей видеокарте (RTX 5060)

## Схема

```
Пользователи Telegram
        │
   [Сервер / VPS]  ← бот (Docker), база, круглосуточно
        │  Tailscale (зашифрованная сеть, без проброса портов)
   [ПК с RTX 5060] ← ComfyUI (картинки) + Ollama (текст)
```

Бот работает на сервере, а тяжёлые вычисления уходят на ПК. Если ПК выключен, бот продолжает работать:
на запросы отвечает «нейросеть перегружена», и лимит не списывается. Можно запустить всё на одном ПК
(`scripts/windows/start_bot.bat`), но тогда бот живёт, только пока ПК включён.

## Что потянет RTX 5060 (8 ГБ видеопамяти)

| Задача | Модель | Видеопамять | Скорость (ориентир) |
|---|---|---|---|
| Картинки | SDXL 1.0 (1024×1024, 28 шагов) | ~6–7 ГБ | ~8–15 с на картинку |
| Картинки | FLUX.1 schnell fp8 (4 шага) | не влезает целиком, часть уходит в RAM (нужно 32 ГБ ОЗУ) | ~15–30 с |
| Текст | qwen2.5:7b (Q4) | ~5 ГБ | 30–50 токенов/с |
| Текст | qwen2.5:3b (Q4) | ~2,5 ГБ | 60+ токенов/с |

**Важно:** SDXL и 7B-модель одновременно в 8 ГБ не помещаются, они будут вытеснять друг друга и всё
замедлится. Варианты, от лучшего к худшему:

1. **Видеокарта рисует, текст идёт через API.** Текст через API стоит копейки (DeepSeek: доли копейки
   за ответ), а по качеству API-модели заметно сильнее 7B. В `.env`:
   `LLM_BASE_URL=https://api.deepseek.com/v1`, `LLM_API_KEY=...`, `LLM_MODEL=deepseek-chat`
   (или любой агрегатор с оплатой картой РФ: VseGPT, ProxyAPI и т.п.).
2. **Маленькая модель рядом с SDXL:** `LLM_MODEL=qwen2.5:3b`. Помещается вместе с SDXL впритык.
3. **Текст на CPU сервера** (Ollama на сервере, модель 3B): бесплатно, но медленно (5–10 токенов/с).

Перевод описаний картинок на английский (`IMAGE_TRANSLATE=true`) тоже идёт через LLM, так что вариант 1
разгружает видеокарту и здесь.

## Установка на Windows-ПК

1. Обнови драйвер NVIDIA (Game Ready или Studio, последний).
2. Открой PowerShell **от администратора** в папке проекта:
   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\scripts\windows\setup_gpu_pc.ps1
   ```
   Скрипт поставит Ollama, 7-Zip и Tailscale, скачает ComfyUI portable (сборка с поддержкой RTX 50xx),
   модель SDXL (~7 ГБ) и языковую модель, а также откроет порты только для сети Tailscale.
   Параметры: `-LlmModel qwen2.5:3b`, `-SkipLlm` (если текст идёт через API), `-SkipSdxl`, `-Dir D:\AI`.
3. Войди в Tailscale на ПК и на сервере под одним аккаунтом
   (на сервере: `curl -fsSL https://tailscale.com/install.sh | sh && sudo tailscale up`).
4. Запусти `C:\AI\start_comfyui.bat` и перезапусти Ollama из трея.
5. Узнай IP ПК в Tailscale: `tailscale ip -4` (что-то вроде `100.101.102.103`).
6. На сервере в `.env`:
   ```
   LLM_BASE_URL=http://100.101.102.103:11434/v1
   IMAGE_BACKEND=comfyui
   IMAGE_API_URL=http://100.101.102.103:8188
   IMAGE_MODEL=sd_xl_base_1.0.safetensors
   ```
   и перезапусти бота: `docker compose up -d`.
7. Проверка с сервера: `curl http://100.101.102.103:8188/system_stats` и
   `curl http://100.101.102.103:11434/api/tags`.

Чтобы ПК не засыпал: Параметры → Система → Питание → «Переход в спящий режим: Никогда».
Автозапуск ComfyUI: положи ярлык `start_comfyui.bat` в `shell:startup`.

## Модели для картинок и лицензии

Бот платный, поэтому модель должна разрешать **коммерческое использование**:

- ✅ **SDXL 1.0** (Stability AI, CreativeML Open RAIL++-M) — ставится скриптом.
- ✅ **FLUX.1 schnell** (Apache 2.0) — `workflows/flux_schnell.json`, файл `flux1-schnell-fp8.safetensors`
  (Comfy-Org на Hugging Face) в `models/checkpoints`, в `.env`: `COMFY_WORKFLOW=workflows/flux_schnell.json`,
  `IMAGE_MODEL=flux1-schnell-fp8.safetensors`.
- ⚠️ **FLUX.1 dev** — только некоммерческая лицензия, в платном боте без отдельной лицензии не использовать.
- Дообученные SDXL-модели (Juggernaut XL, RealVisXL и др.) рисуют заметно лучше базовой SDXL.
  Перед использованием проверь лицензию на странице модели.

Свой workflow из ComfyUI: включи в настройках «Dev mode», нажми «Save (API Format)», положи JSON в
`workflows/` и вставь плейсхолдеры `{{prompt}}`, `{{negative}}`, `{{seed}}`, `{{width}}`, `{{height}}`,
`{{steps}}`, `{{cfg}}`, `{{checkpoint}}` в нужные поля.

## Если нет ComfyUI, но есть Forge / A1111

Запусти с флагом `--api` и укажи `IMAGE_BACKEND=a1111`, `IMAGE_API_URL=http://<ip>:7860`.

## Мощность

Одна RTX 5060 на SDXL — примерно 250–400 картинок в час. Этого хватит на несколько тысяч активных
пользователей в день. Очередь общая: Premium-пользователи идут первыми, остальные видят своё место в очереди.
