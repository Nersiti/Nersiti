# Прокачка

30-дневная программа на массу для Android. Каждый день подбирает упражнения под доступный инвентарь.
Работает полностью офлайн, без сервера и аккаунтов.

## Сборка

```bash
./gradlew -p core test          # тесты ядра, Android SDK не нужен
./gradlew :app:assembleDebug    # APK: app/build/outputs/apk/debug/
```

Готовый debug APK собирает GitHub Actions (`.github/workflows/prokachka.yml`) на каждый пуш:
он лежит в артефактах запуска, называется `prokachka-debug-apk`.

Подпись релиза: создай `keystore.properties` рядом с `settings.gradle.kts`
(поля `storeFile`, `storePassword`, `keyAlias`, `keyPassword`) и запусти `./gradlew :app:assembleRelease`.

## Структура

| Путь | Что внутри |
| --- | --- |
| `core/` | Ядро на чистом Kotlin: `exercises.json` (93 упражнения), `ProgressionEngine`, `WorkoutGenerator`, календарь программы, уровни, серия, ачивки. 36 unit-тестов |
| `app/data/` | Room (состояние программы, прогресс по паттернам, журнал, фото, тесты, замеры), DataStore, резервная копия |
| `app/ui/` | Экраны на Jetpack Compose |
| `app/work/` | Ежедневные напоминания через WorkManager |
| `tools/simulate.py` | Прогон 30 дней по формуле для подбора коэффициентов |

## Главные решения

- **Прогресс хранится по паттерну движения** (жим, тяга, присед…), а не по упражнению. Нет турника — спина тренируется
  другим упражнением, уровень не теряется.
- **Формула:** `цель = база × (1 + k × (день − день_старта + поправка))`. Выше потолка упражнение сменяется следующим
  на лестнице, база сбрасывается до 8 повторов (20 с).
- **Гантели и гиря:** двойная прогрессия 8→12 повторов, затем вес больше. Для веса k удвоен: с обычным k повторы доходили
  бы до 12 только к 38-му дню, и вес внутри цикла не рос бы.
- **Дни:** тренировочный засчитывается после выполнения, день отдыха проходит сам. Перерыв 3+ дня даёт поправку −2.

## Статус по этапам плана

| Этап | Статус |
| --- | --- |
| 1. Каркас | готов |
| 2. Ядро и тесты | готово |
| 3. Основные экраны | готовы |
| 4. Фото | готово: CameraX, «призрак», контур, таймер, кнопка громкости, приватное хранение |
| 5. Прогресс | готов: графики, календарь, серия, уровни, ачивки, адаптация по оценкам |
| 6. Полировка | напоминания, тёмная/светлая тема, резервная копия готовы; иллюстраций упражнений пока нет |
| 7. Финал и циклы | 30-й день, «было → стало», новые циклы готовы; таймлапс — просмотр в приложении, без экспорта в видео |
| 8. Релиз | подпись настроена; публикация в RuStore / Google Play — вручную |

Отличия от плана: упражнения лежат в `exercises.json` внутри ядра, а не в таблице Room; графики нарисованы
на Canvas без библиотеки Vico.
