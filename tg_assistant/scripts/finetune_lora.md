# Опциональное LoRA-дообучение под твой стиль (не обязательно)

Цель: чтобы локальная модель отвечала твоим стилем. Обучения с нуля НЕТ —
только лёгкий адаптер (QLoRA 4-bit) поверх готовой 7–8B модели.

Реалистичность на RTX 5060 (8 GB) / 16 GB RAM:
- QLoRA 4-bit для 7B — влезает, но медленно. Это нормально.
- Батчи маленькие, gradient checkpointing включён, seq len 1024–2048.

Шаги (делает человек, вручную, раз в N дней):
1. Экспорт датасета из архива: выбрать ТВОИ исходящие сообщения как ответы,
   предыдущие сообщения собеседника — как вход. Формат — инструкции (JSONL):
   {"messages":[{"role":"user","content":"..."},{"role":"assistant","content":"<твой ответ>"}]}
   (можно написать отдельный скрипт export_dataset.py по этому формату.)
2. Обучение через unsloth (самый экономный по VRAM):
   - базовая модель: та же, что в Ollama (напр. Qwen2.5-7B-Instruct);
   - load_in_4bit=True, LoRA r=16, alpha=16;
   - 1–3 эпохи, следить за VRAM.
3. Слить/сохранить адаптер -> GGUF -> Modelfile для Ollama:
   FROM qwen2.5:7b-instruct
   ADAPTER ./adapter.gguf
   затем `ollama create my-style -f Modelfile`
4. В config.yaml поставить ai.model: "my-style".

Важно: это управляемый и обратимый процесс. Модель НЕ переписывает себя
сама на лету — это осознанный ручной цикл дообучения.
