## Контекст (что уже готово)
- Репозиторий `Nersiti/Nersiti`, ветка `claude/telegram-ai-integration-2s8p32`,
  проект в `tg_assistant/`. Главный план: `docs/PLAN_WINDOWS.md`.
- **Бэкенд-логика реализована и протестирована** (`pytest` — 8/8):
  - хранилище SQLite+FTS5 (сообщения, медиа, видео-индекс, счётчики);
  - видео: дедупликация по хэшу + «скидывание» с подсчётом
    (`media/video_manager.py`);
  - чистка каналов по промту (`telegram/channels.py`);
  - ИИ (Ollama), автоответ, локальный API.

## ФАЗА 1. Поднять и проверить логику
```
cd tg_assistant
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements.txt
pytest -q            # должно быть 8 passed
```
DONE: тесты зелёные. Архив-папка создаётся автоматически в `C:\Users\<имя>\NersitiArchive`.

- Кнопка «Ассистент» открывает/прячет ИИ-чат (ответит после подключения Ollama).
DONE: окно работает, пароль пускает, видео-дедуп и счётчики работают.

## ФАЗА 4. Подключить Telegram (Telethon) — ГЛАВНОЕ, что осталось
УЖЕ ГОТОВО и работает безголово: `python run_telegram.py` (логин + живая
архивация всех чатов/каналов/медиа/видео с дедупом; `--backfill N` тянет
историю; `--clean "промт"` чистит каналы по промту с подтверждением).
Модули `telegram/client.py`, `telegram/collector.py`, `telegram/channels.py`
готовы и покрыты тестами. Твоя задача — ВСТРОИТЬ это в GUI:
В `nersiti_tg/desktop/main.py` есть блок `# TODO(Telegram)`. Реализуй:
1. Авторизация Telethon по `TG_API_ID/HASH` (первый вход — код/2FA в окне),
   сессия в файле архива.
2. Связка async-loop Telethon с Qt: используй `qasync` (pip install qasync)
   ИЛИ отдельный поток с asyncio.
3. Заполни вкладку «Чаты и каналы» реальными диалогами.
4. Фоновая архивация входящих: пиши в БД (`storage.db`) и качай медиа в
   `media/<chat_id>/...`; видео дополнительно прогоняй через
   `VideoManager.drop_video` (дедуп + счётчик).
5. Экран «Чистка каналов»: поле промта -> `ChannelManager.propose_cleanup`
   (показать список на выход) -> кнопка «Подтвердить» -> `leave_channels`.
6. Дай ИИ-чату простые инструменты: поиск по архиву, список каналов, запуск
   чистки/дедупа (tool-роутер).
DONE: в приложении видны реальные чаты/каналы; входящие архивируются; видео
скидываются со счётчиком; чистка каналов по промту работает с подтверждением.

## ФАЗА 5. Собрать .exe
```
pip install pyinstaller
pyinstaller --noconfirm --windowed --name Nersiti --collect-all PySide6 ^
  nersiti_tg\desktop\main.py
```
Готовый `dist\Nersiti\Nersiti.exe`. Проверь запуск двойным кликом.
DONE: exe запускается, просит пароль, всё работает.
