# ПЛАН: десктоп-приложение под Windows (замена мода APK)

> Решение пользователя: делаем НЕ APK, а Windows-приложение. Строгий чёрный
> стиль. Пароль при каждом входе. Встроенный ИИ-чат под иконкой. ИИ имеет
> полный доступ ко всем чатам и каналам. Чистка каналов по промту. Видео:
> искать одинаковые и чистить дубли, «скидывать» видео с подсчётом. Весь
> архив — в отдельную папку (создаётся автоматически). Плюс всё, что раньше.
>
> APK-путь (docs/PLAN_MOD_ANDROID.md, docs/BUILD_APK.md, android_mod/) —
> ЗАМОРОЖЕН, оставлен в репозитории на будущее.

## 0. Архитектура

Одно Windows-приложение (Python), внутри:
- **GUI** — PySide6 (Qt), строгая чёрная тема. Файл `nersiti_tg/desktop/main.py`.
- **Пароль входа** — при каждом старте (SHA-256 из `config.security`,
  по умолчанию = хэш "Logingood123337"). Модуль `nersiti_tg/auth.py`.
- **Доступ к Telegram** — Telethon (userbot) под аккаунтом пользователя:
  все чаты, каналы, история, медиа, скачивание видео.
- **ИИ** — локальная модель через Ollama (чат-ассистент + чистка каналов).
- **Хранилище** — SQLite+FTS5 + папка архива (см. §5). Реализовано.
- **Видео** — дедупликация по хэшу + счётчики. Модуль
  `nersiti_tg/media/video_manager.py`. Реализовано и протестировано.

Всё, кроме живого Telegram-подключения, работает in-process и покрыто тестами.

## 1. Что уже готово (реализовано, pytest зелёный)
- `config.py` — настройки, включая security (пароль) и video; папка архива
  по умолчанию `~/NersitiArchive`, создаётся при старте (`ensure_dirs`).
- `auth.py` — проверка пароля (SHA-256).
- `storage/db.py` — архив, поиск, черновики, настройки чатов, **таблицы
  videos (дедуп) и counters (подсчёт)**.
- `media/video_manager.py` — `drop_video` (скинуть+дедуп), `dedup_folder`
  (чистка дублей), `stats` (счётчики скинутых/дублей).
- `telegram/channels.py` — ChannelManager: `list_channels`, `propose_cleanup`
  (ИИ по промту предлагает, что удалить), `leave_channels` (выход после
  подтверждения). Разбор решения ИИ протестирован.
- `ai/*`, `autoreply/*`, `dashboard/app.py` (локальный API + видео-эндпоинты).
- `desktop/main.py` — каркас GUI: пароль, чёрная тема, вкладки
  (Чаты/Видео/Настройки), скрытый ИИ-чат под кнопкой «💬 Ассистент».

## 2. Что доделать (для исполнителя/Cowork)
A. **Telegram-подключение (Telethon) в десктопе** — главный оставшийся кусок:
   - авторизация по api_id/api_hash пользователя (первый вход — код/2FA);
   - интеграция с Qt: async-loop через `qasync` или отдельный поток;
   - заполнить список чатов/каналов в GUI из реальных диалогов;
   - фоновая архивация входящих (в БД + медиа на диск);
   - скачивание видео из чатов -> `VideoManager.drop_video` (счётчик растёт).
B. **Чистка каналов по промту** — экран: поле промта -> `propose_cleanup`
   показывает список на выход -> кнопка «Подтвердить» -> `leave_channels`.
C. **Видео-раздел** — уже есть кнопки «Скинуть видео» и «Чистка дублей»;
   добавить авто-скидывание видео из выбранных чатов и наглядные счётчики.
D. **ИИ-чат** — уже дёргает Ollama; дать ему инструменты (доступ к архиву,
   к списку каналов, запуск чистки) через простой tool-роутер.
E. **Упаковка в .exe** — PyInstaller (см. §6).

## 3. Строгий чёрный стиль
Тема задаётся QSS в `desktop/main.py` (DARK_QSS): фон #060–#0a0a0a, панели
#111–#161616, границы #262626, текст #e6e6e6, акценты приглушённые. Без ярких
цветов; ошибки — сдержанный красный. Минимализм, много «воздуха».

## 4. Пароль входа
При каждом запуске — `PasswordDialog`. Сверяется SHA-256 введённого с
`config.security.password_sha256`. По умолчанию — хэш "Logingood123337"
(в репозитории только хэш, не открытый пароль). Сменить пароль = положить
новый SHA-256 в config.

## 5. Папка архива (создаётся сама)
Корень: `config.storage.data_dir`, по умолчанию `C:\Users\<имя>\NersitiArchive`.
Приложение создаёт при первом запуске:
- `archive.db` — база (сообщения, видео-индекс, счётчики);
- `media/<chat_id>/<yyyy-mm>/` — файлы из чатов;
- `videos/` — «скинутые» видео (после дедупликации);
- `persona.md`, `app.log`.

## 6. Сборка .exe (Windows)
```
pip install -r requirements.txt pyinstaller
pyinstaller --noconfirm --windowed --name Nersiti ^
  --collect-all PySide6 nersiti_tg/desktop/main.py
```
Готовый `Nersiti.exe` — в `dist/Nersiti/`. Для работы ИИ рядом должен быть
запущен Ollama (см. scripts/setup_model). Telegram — вход при первом старте.

## 7. Риски/честно
- userbot-автоматизация — серая зона правил Telegram; массовые действия
  (чистка каналов, авто-ответы) повышают риск ограничений аккаунта.
- Чистка каналов необратима -> всегда двухшагово (предпросмотр + подтверждение).
- ИИ-«понимание» видео НЕ используется (по решению пользователя) — только
  дедуп по хэшу; это быстро, точно и без нагрузки на GPU.
