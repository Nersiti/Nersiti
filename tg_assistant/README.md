# Nersiti TG Assistant

Локальный ИИ-ассистент «поверх» твоего Telegram: архивирует все сообщения и
файлы, ищет по ним и помогает отвечать с помощью **локальной** модели (Ollama).
Ничего не уходит в облако.

> Статус: каркас + подробное ТЗ. Реализацию модулей пишет модель-исполнитель
> по документу **docs/PLAN.md**. Начинать — с раздела §12 «Порядок реализации».

## Что умеет (по плану)
- **Архив всего**: каждое сообщение, правки и удаления, все фото/видео/файлы
  → SQLite (+FTS5) и папка `data/media/`.
- **Поиск** по всему архиву (полнотекстовый, опц. семантический).
- **Автоответ** локальной моделью, режимы на каждый чат:
  - `off` — выключено;
  - `draft` (кнопка) — ИИ пишет черновик, ты подтверждаешь и отправляешь;
  - `auto` (тумблер) — отвечает сам: `preset` (заготовка) /
    `generate` (сочиняет ответ) / `dialogue` (ведёт диалог с контекстом).
- **Веб-панель** на `localhost`: тумблеры, режимы, очередь черновиков, поиск.

## Требования
- Python 3.11
- [Ollama](https://ollama.com) + модель, напр. `ollama pull qwen2.5:7b-instruct`
  (или `dolphin-mistral:7b` для варианта без цензуры).
- `api_id` / `api_hash` с https://my.telegram.org
- Железо-ориентир: RTX 5060 8 GB / 16 GB RAM / Ryzen 5 5500 — тянет одну
  квантованную 7–8B модель в Q4.

## Установка
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env            # вписать TG_API_ID/HASH и пароль панели
cp config.example.yaml config.yaml   # выбрать модель и режимы
python run.py                   # первый запуск — вход в Telegram по коду
```
Панель: http://127.0.0.1:8765

## Про «без ограничений» и «самообучение»
- «Без ограничений» = выбор uncensored-модели в Ollama, отдельной тренировки
  для этого не нужно.
- «Самообучение» реализуется реалистично: редактируемая память/персона +
  опциональный ручной LoRA под твой стиль (`scripts/finetune_lora.md`).
  Модель **не переписывает свои веса на лету** — на этом железе это нереально
  и небезопасно.

## Важно (правила Telegram)
Автоматизация действий от личного аккаунта (userbot) — серая зона правил
Telegram; полный `auto`-режим повышает риск ограничений аккаунта. По
умолчанию стоит `draft` (с ручным подтверждением). Архивируются только твои
собственные чаты, всё хранится локально.
