# Nersiti AI — Telegram-бот, который зарабатывает

ИИ-бот для Telegram: **чат с нейросетью + генерация картинок**. Работает на твоей видеокарте (RTX 5060),
поэтому себестоимость запроса почти нулевая, а деньги приходят в **Telegram Stars**. Рубли (ЮKassa и
другие провайдеры) подключаются одной строкой в `.env`.

## Что умеет

| Для пользователя | Для владельца |
|---|---|
| 💬 ИИ-чат с памятью диалога, ответ «печатается» на глазах | 💰 Оплата в Telegram Stars «из коробки» |
| 🎨 Картинки по описанию на русском: 8 стилей, 5 форматов | 🔁 Подписка Premium за Stars с автопродлением |
| 🎁 Бесплатный лимит каждый день + ежедневный бонус | 💳 Рубли: через провайдера в Telegram или ЮKassa напрямую |
| 👥 Реферальная программа: бонусы за друзей и 10% с их покупок | 📊 Статистика, источники трафика, доход, конверсия |
| 🎟 Промокоды | 📢 Рассылки, реклама в боте, обязательная подписка на каналы |
| 💎 Premium: приоритетная очередь, без рекламы | 🖼 Автопостинг картинок в канал-витрину со ссылкой на бота |

## Как бот приносит деньги

1. **Freemium.** Каждый день бесплатно 15 сообщений и 3 картинки — достаточно, чтобы «подсесть»,
   мало, чтобы не захотеть больше.
2. **Кредиты** (50–990 ⭐) — для тех, кому нужно иногда. Не сгорают.
3. **Premium-подписка** 299 ⭐/мес с автопродлением — основной доход, повторяется каждый месяц.
4. **Реклама внутри бота** (`/setad`) и **платная обязательная подписка** на чужие каналы (`/channels`) —
   продаются владельцам каналов, когда наберётся аудитория.
5. **Платные рассылки** (`/broadcast`) по базе пользователей.

Цены меняются в `app/products.py`, лимиты — в `.env`. План продвижения — в [promo/PROMOTION.md](promo/PROMOTION.md).

## Быстрый старт

### 1. Создай бота
1. Открой [@BotFather](https://t.me/BotFather) → `/newbot` → получи токен.
2. Там же: `/setuserpic` (аватар — можно нарисовать этим же ботом), `/setname` — см. советы по названию в
   [promo/PROMOTION.md](promo/PROMOTION.md).
3. Для Stars ничего подключать не нужно.

### 2. Запусти на сервере (Docker)
```bash
git clone <этот репозиторий> nersiti && cd nersiti
cp .env.example .env
nano .env                  # BOT_TOKEN, ADMIN_IDS, SUPPORT_CONTACT
bash deploy/setup_server.sh
```
Свой Telegram ID можно узнать командой `/id` в боте. Логи: `docker compose logs -f bot`.

> Проверить бота без нейросетей: в `.env` поставь `LLM_BACKEND=mock` и `IMAGE_BACKEND=mock` —
> бот будет отвечать «эхом» и рисовать градиенты, а оплата будет работать по-настоящему.

### 3. Подключи нейросети
- **ПК с RTX 5060** — скрипт `scripts/windows/setup_gpu_pc.ps1` поставит ComfyUI, Ollama, модели и Tailscale.
  Подробно: [docs/GPU.md](docs/GPU.md).
- **Или API** — любой OpenAI-совместимый (DeepSeek, OpenRouter, VseGPT…) для текста: поменяй
  `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`.

### 4. Рубли (когда будешь готов)
Одна из двух схем, подробно в [docs/PAYMENTS.md](docs/PAYMENTS.md):
- `RUB_PROVIDER_TOKEN` — оплата картой прямо в Telegram (ЮKassa, Robokassa и др. через @BotFather);
- `YOOKASSA_SHOP_ID` + `YOOKASSA_SECRET_KEY` — ссылка на оплату картой/СБП через ЮKassa.

Когда подключено несколько способов, бот сам предложит пользователю выбор.

## Команды администратора

Отправь боту `/admin`.

| Команда | Что делает |
|---|---|
| `/stats` | пользователи, активность, Premium, доход за сегодня и всего |
| `/sources` | откуда пришли пользователи, сколько из них платят, доход по каждому источнику |
| `/link vk_post1` | ссылка для рекламы с меткой источника |
| `/user 123` / `/user @name` | карточка пользователя |
| `/give 123 100` | начислить (или списать с минусом) кредиты |
| `/premium 123 30` | подарить Premium |
| `/ban 123`, `/unban 123` | бан |
| `/promo_new BLOG 50 100 0 30` | промокод: 50 кредитов, 100 активаций, 0 дней Premium, живёт 30 дней |
| `/promos` | список промокодов |
| `/refund <charge_id>` | вернуть звёзды (charge_id приходит в уведомлении об оплате) |
| `/broadcast` | ответь этой командой на любое сообщение — бот разошлёт его всем |
| `/setad <html>` / `/setad off` | реклама для бесплатных пользователей |
| `/channels set @a,@b` / `off` / `reset` | обязательная подписка на каналы |
| `/showcase` | опубликовать картинку в канал-витрину прямо сейчас |

## Структура проекта

```
app/
  main.py              сборка бота, фоновые задачи
  config.py            все настройки (.env)
  products.py          товары и цены
  texts.py             все тексты бота
  keyboards.py         кнопки
  handlers/            обработчики: ai, payments, bonus, menu, common, admin
  services/
    billing.py         лимиты и списания (атомарно, без гонок)
    llm.py             клиент OpenAI-совместимого API (Ollama, DeepSeek…)
    images/            ComfyUI, A1111/Forge, OpenAI Images, заглушка
    queue.py           очередь GPU с приоритетом для Premium
    payments/          Stars, рубли через Telegram, ЮKassa
    growth.py          рефералы, метки источников, рассылки, канал-витрина
    channels.py        обязательная подписка
    moderation.py      фильтр запросов 18+
  db/                  модели и запросы (SQLite или PostgreSQL)
workflows/             workflow для ComfyUI (SDXL, Flux schnell)
promo/                 план продвижения, рекламные тексты, промпты для витрины
deploy/                установка на сервер, systemd, бэкапы
scripts/windows/       настройка ПК с видеокартой
tests/                 тесты с имитацией Telegram API
```

## Разработка

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
pytest                      # тесты (SQLite)
TEST_DATABASE_URL=postgresql+asyncpg://user@host/db pytest   # на PostgreSQL
python -m app               # запуск
```
