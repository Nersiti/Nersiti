# «Хозяин Слова»: Telegram-игра, где можно завладеть любым словом мира

**Идея, которой раньше не было:** каждое слово в мире может принадлежать только одному человеку.
Кто первым написал слово боту, тот им и владеет. Навсегда (пока не отберут).

- ✒️ Пишешь любое слово: «бывший», «налоговая», «Wi-Fi в метро». Если оно свободно, захватываешь его.
- 🧠 Нейросеть превращает слово в существо: имя, стихия, класс, способность, характеристики, история.
  Видеокарта (RTX 5060) рисует арт, бот собирает карту. Редкость выпадает случайно, от ⚪ обычной
  до 🔴 мифической.
- ⚔️ Карты сражаются. Чужое слово можно **захватить в бою**: ставишь его ценность в кристаллах и
  побеждаешь. Владелец получает уведомление «на твоё слово напали!» и ставку в любом случае.
- 💰 Слова можно **выкупать** друг у друга, защищать **щитами** и прокачивать в боях.
- 🔨 Каждый день идёт **аукцион «горячего» слова** («любовь», «деньги», «пятница»…). Их нельзя
  захватить пером, только выиграть на торгах.
- 📤 В любом чате пишешь `@бот слово` и показываешь свою карту. Игра распространяется сама.

### Почему игроки возвращаются
- 🚨 «На твоё слово напали!» — уведомление при каждой попытке захвата.
- ⏰ «Иммунитет закончился — отбей своё слово!» — напоминание тому, у кого слово отобрали.
- 🏅 **Турнир недели**: победы в боях дают очки, по понедельникам лучшие получают кристаллы.
  Очки — это выигранный рейтинг Эло, поэтому накрутка на слабых фейках почти ничего не даёт.
- 🔨 Аукцион каждый день в 12:00, 🎁 ежедневный бонус, мягкое напоминание раз в неделю тем, кто пропал.
- 🛡 Новичков берегут: первое слово — минимум редкое, последнее слово игрока захватить нельзя.

## Как игра приносит деньги

| Источник | Как работает |
|---|---|
| 💎 **Кристаллы** (50–990 ⭐) | перья сверх 3 бесплатных в день, захваты, щиты, выкуп чужих слов, ставки на аукционах |
| 👑 **Лорд** 249 ⭐/мес, автопродление | 10 слов и 30 боёв в день, почти вдвое выше шанс легендарок, комиссия 5%, +100 💎 каждый месяц |
| 🔨 **Аукционы** | ежедневные торги за легендарные слова; кристаллы сгорают, поэтому их покупают снова |
| 🛡 **Страх потери** | на твоё слово напали — хочется поставить щит или отбить его обратно |
| ⏳ **Окончание статуса** | когда «Лорд» закончился, бот сам предлагает продлить |
| 📢 **Реклама и спонсоры** | реклама между боями (`/setad`), платная обязательная подписка на каналы (`/channels`) |

Оплата в **Telegram Stars** работает сразу. **Рубли** (ЮKassa или другой провайдер) подключаются
одной строкой в `.env`. Подробно: [docs/PAYMENTS.md](docs/PAYMENTS.md).

## Запуск

### 1. Бот в Telegram
1. [@BotFather](https://t.me/BotFather) → `/newbot` → получи токен.
2. `/setinline` → включи инлайн-режим (placeholder: `слово…`): это вирусный канал `@бот слово`.
3. `/setname`, `/setuserpic`: советы в [promo/PROMOTION.md](promo/PROMOTION.md).

### 2. Сервер (Docker)
```bash
git clone <этот репозиторий> word-lord && cd word-lord
cp .env.example .env
nano .env                  # BOT_TOKEN, ADMIN_IDS, SUPPORT_CONTACT
bash deploy/setup_server.sh
```
Свой Telegram ID можно узнать командой `/id` в боте. Логи: `docker compose logs -f bot`.

> Проверить без нейросетей: `LLM_BACKEND=mock` и `IMAGE_BACKEND=mock`. Существа будут создаваться
> по шаблону, арт заменят градиенты, а игра и оплата будут работать полностью.

### 3. Нейросети на твоей RTX 5060
Скрипт `scripts/windows/setup_gpu_pc.ps1` ставит ComfyUI, Ollama, модели и Tailscale.
Подробно: [docs/GPU.md](docs/GPU.md). Если видеокарта выключена, игра не встаёт: карта создаётся
с заглушкой, а арт можно бесплатно дорисовать позже кнопкой «🎨 Дорисовать арт». Предохранители не
заставляют игроков ждать таймаутов: после первой ошибки бот на минуту перестаёт стучаться в ПК.

### 4. Проверка
При каждом запуске бот присылает администраторам отчёт: видит ли он нейросеть, ComfyUI и нужную
модель, какие способы оплаты включены. Проверить вручную — `/health`.

## Команды администратора (`/admin`)

| Команда | Что делает |
|---|---|
| `/stats` | игроки, активность, Лорды, слова, бои, доход |
| `/sources` | откуда пришли игроки, сколько платят, доход по источникам |
| `/link tiktok1` | ссылка для рекламы с меткой источника |
| `/user 123` · `/give 123 100` · `/premium 123 30` | карточка игрока, начисление кристаллов, выдача статуса Лорда |
| `/ban` · `/unban` · `/delcard слово` · `/recent` | модерация: бан, удаление карты, список новых слов |
| 🚩 на карте | игроки жалуются на карту, админ получает её с кнопкой «Удалить» |
| `/health` | проверить нейросеть, художника (и модель) и оплату |
| `/auction_start слово 6` | запустить аукцион вручную (на 6 часов) |
| `/promo_new КОД 50 100 0 30` · `/promos` | промокоды: 50 💎, 100 активаций, живёт 30 дней |
| `/refund <charge_id>` | вернуть звёзды (charge_id приходит в уведомлении об оплате) |
| `/broadcast` | ответь этой командой на сообщение, и бот разошлёт его всем |
| `/setad <html>` · `/channels set @a,@b` | реклама между боями, обязательная подписка |

## Что где лежит

```
app/
  game/
    words.py           нормализация слов, список аукционных слов (reserved_words.txt)
    genesis.py         нейросеть придумывает существо по слову (+ запасной генератор)
    rules.py           редкости, стихии, классы, уровни, ценность, рейтинг Эло
    battle.py          боевой движок (исход считается по характеристикам, LLM только рассказывает)
    render.py          отрисовка карты (Pillow)
    service.py         захват слов, бои, захваты, щиты, выкуп, топы: всё атомарно, без гонок
    auction.py         ежедневный аукцион с защитой от снайперских ставок
    retention.py       удержание: «месть», турнир недели, напоминания, окончание статуса
  handlers/            game (игра), inline (инлайн и группы), payments, bonus, common, admin
  services/            нейросети и предохранители, очередь GPU, оплата (Stars, рубли, ЮKassa), рефералы, каналы
  db/                  модели и запросы; новые поля добавляются в базу автоматически при запуске
  products.py          цены
  texts.py             все тексты
assets/fonts/          шрифты для карт (DejaVu, свободная лицензия)
workflows/             workflow ComfyUI (SDXL, Flux schnell)
promo/                 план продвижения и рекламные тексты
deploy/ scripts/       сервер, systemd, бэкапы, настройка ПК с видеокартой
tests/                 тесты с имитацией Telegram API (SQLite и PostgreSQL)
```
