# Nersiti

Игровой сайт с подборкой ссылок на крутые игры: поиск, фильтр по жанрам,
кнопка «Случайная игра» и ссылки только на официальные сайты.

## Файлы

| Файл          | Что внутри                                  |
| ------------- | ------------------------------------------- |
| `index.html`  | Разметка страницы                           |
| `style.css`   | Оформление (тёмная тема, адаптив под телефон) |
| `games.js`    | **Список игр** — его нужно менять чаще всего |
| `script.js`   | Поиск, фильтры и случайная игра              |
| `favicon.svg` | Иконка сайта во вкладке браузера             |

## Как добавить игру

Открой `games.js`, скопируй любой блок `{ ... }` и поменяй поля:

```js
{
  title: "Название игры",
  genre: "Шутер",                 // из жанров сами собираются кнопки-фильтры
  platforms: ["ПК", "Телефон"],
  free: true,                     // true — бесплатная, false — платная
  description: "Пара слов об игре.",
  url: "https://официальный-сайт-игры/",
  color: "#3d5a80",               // цвет обложки
},
```

## Как посмотреть сайт

Просто открой `index.html` в браузере — сервер не нужен.

## Как выложить в интернет (GitHub Pages)

1. В репозитории на GitHub открой **Settings → Pages**.
2. В **Source** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`.
3. Нажми **Save** — через минуту сайт появится по адресу
   `https://nersiti.github.io/nersiti/`.
