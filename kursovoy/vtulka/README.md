# Иллюстрации к курсовому — деталь «Втулка» КИКГ.010114.002

Картинки к КП «Разработка технологического процесса механической обработки
детали "Втулка"» (Пугачёв А.Д., гр. 201). Всё считается скриптами, без КОМПАСа.

## Геометрия детали

Размеры с чертежа КИКГ.010114.002, сверены с пояснительной запиской
(расчёт массы, п. 2.2.2):

| Элемент | Размер |
|---|---|
| Буртик | Ø55h14, ширина 5 мм (7…12 от левого торца) |
| Наружные цилиндры | Ø40h14 (слева 7 мм, справа 26 мм) |
| Отверстие | Ø30H9, Ra 1,6, насквозь |
| Пазы в буртике | 6 × 3 мм, 4 шт. (по виду справа на чертеже) |
| Общая длина | 38 мм (размер справочный) |
| Фаски | 2×45° по всем кромкам |
| Материал | Латунь Л62 ГОСТ 15527-70, ρ = 8,5 г/см³, масса 225 г |

Заготовка: пруток горячекатаный Ø58 × 43 мм ГОСТ 2060-2006, масса 966 г.

Проверка: V = π/4·55²·5 + π/4·40²·33 − π/4·30²·38 ≈ 26 490 мм³ — совпадает
с расчётом в записке (формула 2.3), значит модель построена по тем же размерам.

## Расхождение, которое стоит проверить

На чертеже в буртике есть 4 паза 6×3, но в маршруте (табл. 2.4) операции их
изготовления нет — ни фрезерной, ни долбёжной. Либо в ТП нужно добавить
фрезерную операцию, либо пазов на детали быть не должно. В 3D-видах пазы
показаны (как на чертеже), в операционных эскизах — нет (как в вашем ТП).

## Как перегенерировать

```
pip install numpy pillow cairosvg
python render_vtulka.py     # 3D-виды в img/
python sketches.py          # эскизы в img/ (PNG и SVG)
```

Размеры детали — константы в начале `render_vtulka.py`, профили для эскизов —
списки `DETAL / OP015 / OP010 / ZAGOT` в `sketches.py`.

## Оговорка

Это не скриншоты из КОМПАС-3D: КОМПАС работает только под Windows, здесь его
нет. Геометрия построена по размерам чертежа: 3D — трассировкой лучей по
CSG-модели (`csg.py`), эскизы — векторной графикой.
