# Иллюстрации к курсовому проекту — деталь «Крышка»

Картинки к КП «Разработка технологического процесса механической обработки
детали "Крышка"» (СПТК 15.02.16.023). Всё считается скриптами, без КОМПАСа.

## Геометрия детали

Размеры сняты с чертежа (`Крышка.cdw`) и проверены по пояснительной записке:

| Элемент | Размер |
|---|---|
| Фланец | Ø175, толщина 18 мм |
| Центрирующий поясок | Ø90h8(-0,054), длина 26 мм, фаска 2×45° |
| Центральное отверстие | Ø52H7(+0,03) насквозь |
| Крепёжные отверстия | 4 × Ø14 на окружности Ø140 |
| Общая длина | 44 мм |
| Материал | Сталь 30 ГОСТ 1050-2013, масса 3,87 кг |

Толщина фланца 18 мм получена двумя независимыми способами: обмером
чертежа и обратным расчётом из массы 3,87 кг — оба дают 18.

Заготовка (поковка штампованная ГОСТ 7829-70): Ø177,8 × 47, поясок Ø92,7,
отверстие Ø49,7.

## Что в папке `img/`

3D-виды (`render_krishka.py`):

| Файл | Что на нём |
|---|---|
| `krishka_iso.png` | общий вид, фланец сверху |
| `krishka_iso_poyasok.png` | общий вид со стороны пояска, видна фаска |
| `krishka_cut.png`, `krishka_cut_poyasok.png` | четвертной разрез: видно Ø52 и крепёжные отверстия |
| `krishka_front.png`, `krishka_top.png` | вид спереди и вид сверху |
| `zagotovka_iso.png`, `zagotovka_cut.png` | заготовка-поковка |

Операционные эскизы (`oper_sketches.py`), зелёным — обрабатываемая на операции
поверхность, треугольники — базы, стрелки — зажим, размеры пронумерованы:

| Файл | Операция |
|---|---|
| `op_005_zagotovka.png` | 005 Заготовительная (поковка) |
| `op_010_tokarnaya_A.png` | 010 Токарно-винторезная, установ А: торец и Ø175 |
| `op_015_tokarnaya_B.png` | 015 Токарно-винторезная, установ Б: торец, Ø90, фаска, расточка Ø52 |
| `op_020_sverlilnaya.png` | 020 Вертикально-сверлильная: 4 отв. Ø14 |
| `op_025_vnutrishlif.png` | 025 Внутришлифовальная: Ø52H7 |
| `op_030_krugloshlif.png` | 030 Круглошлифовальная: Ø90h8 |

Промежуточные размеры на эскизах взяты из таблицы припусков записки:
47→44; Ø177,8→175; Ø92,7→90,36→90,06→90; Ø49,7→51,64→51,94→52.

## Как перегенерировать

```
pip install numpy pillow cairosvg
python render_krishka.py      # 3D-виды в img/
python oper_sketches.py       # операционные эскизы в img/ (PNG и SVG)
```

Размеры детали задаются словарями `KRISHKA` и `ZAGOTOVKA` в `render_krishka.py`
и `ZAGOT / OP010 / OP015 / FINAL` в `oper_sketches.py` — если на чертеже
что-то другое, поправьте там и запустите заново.

## Оговорка

Это не скриншоты из КОМПАС-3D: КОМПАС — программа под Windows, здесь её нет.
Картинки нарисованы по размерам вашего чертежа собственным рендером
(трассировка лучей по CSG) и векторной графикой.
